FAQ

Pertanyaan umum

Apakah ada kelas gratis?

BoostSkill pernah mengadakan kelas gratis terbuka untuk umum, misalnya Public Speaking Class. Info kelas berikutnya diumumkan di Instagram dan WhatsApp.

Belajarnya online atau offline?

Tersedia on/off course. Format tiap program dikonfirmasi oleh admin.

Bisa kelas private?

Bisa. Kelas private diatur sesuai jadwal dan kebutuhanmu. Chat admin untuk detailnya.

Bisa untuk perusahaan, sekolah, atau komunitas?

Bisa lewat in-house training. Ceritakan kebutuhanmu ke admin, lalu materi disusun bersama.

Apakah dapat sertifikat?

Kelas Public Speaking menyediakan e-sertifikat. Untuk program lain, tanyakan ke admin.

Berapa biayanya?

Biaya berbeda tiap program dan format belajar. Chat admin untuk info terbaru.

Siap upgrade skill kamu?

Konsultasi dulu, gratis. Admin bantu pilihkan kelas yang pas.
